## 4. 演示录屏（3–5 分钟，Claude 录制）
- 录制：Swift + ScreenCaptureKit 小工具录屏幕 + 电脑内声音（与系统录屏同一机制；首次需给终端「屏幕录制」权限）。Playwright 驱动**有界面**的 Chrome 窗口按脚本操作；真实模式。
- 语音输入：macOS `say`（中文音色）生成用户语音文件，作为 Chrome 假麦克风输入（`--use-file-for-fake-audio-capture`）。
- 分镜（约 4 分钟）：
  | 时间 | 内容 | 对应要求 |
  |---|---|---|
  | 0:00–0:25 | 加载、待机（呼吸 / 眨眼 / 状态牌「发呆中」） | 角色状态 |
  | 0:25–1:00 | 文字「还没下播？」→ 思考 → 说话、字幕、表情 | 文字互动、状态变化 |
  | 1:00–1:30 | 按住说话（语音输入）→ 倾听 → 识别 → 回复 | 语音互动 |
  | 1:30–1:50 | 说话中点画面打断 → 立即停、进入倾听 → 接着问 | 打断 |
  | 1:50–2:40 | 「带我去海边吧」→ 生成中状态条 → 生成背景 | 生成媒体 |
  | 2:40–3:30 | 推进剧情：老截图、推镜、stream_dim → 结局 hearts + 离线视频 | 画面变化、视频 |
  | 3:30–4:00 | `?fail=tts` 重开 → 琥珀色兜底字幕；断线提示与重连 | 失败 / 降级 |
  | 4:00–4:15 | 动作表、设置面板、观测页 | 加分项 |
- 依赖 freeze-fix1 的剧情保底推进（否则真实模式走不到结局）。
