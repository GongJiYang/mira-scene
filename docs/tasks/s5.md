## 1. Mock 语音方案 B
- manifest 结构：`{ version: 1, clips: { [voiceKey]: { file: string, text: string, emotion: string, durationMs: number } } }`，音频文件放在 `assets/voice/clips/`，格式 mp3（与 Fish 输出一致）。
- `createMockTts` 新增选项 `manifestPath`：命中就返回预录音频（保留原有 `delayMs` 与 AbortSignal 行为），未命中就返回现有 `synthesizeWav` 占位音，并写 `voice_fallback` 日志。
- 接口按「一句一段音频」设计，不要引入流式或整轮缓存。D37 说明以后要和 E1 实时语音复用这个端口，所以不要把逻辑写死成「只服务 Mock 剧本」，例如 key 的计算不要依赖剧情节点。
- `scripts/record-voices.ts`：遍历 `mockLlm.ts` 里所有台词和对应情绪，调用真实 Fish TTS 适配器合成，写入 clips 和 manifest。已存在的 key 跳过，可以重复运行。在根 `package.json` 加命令 `pnpm voices:record`。报告里写明用法即可，**不要运行**。

## 2. iOS 音频解锁加固
- 现状：`audio.ts` 只在第一次手势时调用一次 `resume()`。
- 改为：每次 `pointerdown` / `keydown` / `touchend` 时，如果 AudioContext 的 state 不是 `running`（iOS 上可能是 `suspended` 或 `interrupted`），就调用 `resume()`。另外在 `visibilitychange` 变为可见时把「需要解锁」标记置位，等下一次手势再解锁。
- 报告里附一份**真机手测清单**（iPhone Safari）：首次进入后点击、切到后台再回来、来电或锁屏后恢复、静音键开着时的表现。

## 3. 竖屏适配
- `index.html` 的 viewport meta 加 `viewport-fit=cover`；页面高度用 `100dvh`；输入栏底部留出 `env(safe-area-inset-bottom)`。
- 任何视口下都不能出现横向滚动。

## 4. S4 遗留
- ① 现在 `orientationFor` 按窗口尺寸判断，桌面横屏窗口会选到 `_h` 素材，在 2:3 舞台里会被裁掉相机。改为用 `pickStageAsset(舞台框尺寸)`，舞台框尺寸由 ResizeObserver 量出。
- ② 照片放大居中时会挡住角色的脸。在 `layers.ts` 或 manifest 里给角色定义一个 `faceBox`（以舞台百分比表示，按当前占位角色的脸部位置标定，在报告里写明数值），放大态的位置和尺寸改由 `photoRect` 计算。

## 5. WebM 剧情视频（题目 §5：加载 / 播放结束 / 中途打断）
- **触发**：导演层在 `advancedTo === "ending"` 分支加上 `media = { type: "video", id: "clip_ending" }`。协议里已经有 `"video"` 类型，不要改协议。
- **占位素材**：`scripts/make-placeholder-video.sh` 用 ffmpeg 从 `b1_bg_main_v.png` 交叉淡入到 `b3_bg_closing_v.png`，再加一点缓慢推镜，生成约 6 秒、竖版 2:3、VP9 编码、无音轨的 webm，体积不超过 1.5MB。脚本你可以运行，生成的文件也要放进仓库。
- **四种情况**（视频状态的转移写成纯函数 reducer，并写单测）：
  | 情况 | 表现 |
  |---|---|
  | 加载中 | 常驻角色和舞台照常动，视频层不可见，可以显示一个很小的加载提示；超过 5 秒还没到 `canplay` 就按失败处理 |
  | 播放中 | 视频层淡入覆盖角色区域，字幕照常显示 |
  | 播放结束 | 淡出，回到常驻角色和 closing 背景 |
  | 中途打断（按住说话或提交文字） | 立即暂停并淡出，**不恢复**，状态机 A 进入倾听。这是对 D34「剧情层命令全部保留」的明确例外：照片保留，视频打断就结束。在报告里说明你是怎么实现这个例外的 |
  | 失败（加载错误、超时，或 `?fail=video`） | 视频不出现，改为显示静态图 `b3_bg_closing_v`，并给出一条不打断体验的提示 |
- **契约**：同一时刻最多只有一个视频在播；任何状态下 turnId 失效的视频都不能出现。用 fast-check 随机生成 load / canplay / ended / interrupt / error 事件序列（1000 次），断言这两条恒成立。
- **e2e**：Mock 模式下把剧情推进到 ending，断言视频出现；在播放中按住说话，断言 300ms 内视频不可见且没有恢复；`?fail=video` 时断言出现的是静态图。
