## 铁律
冲突停下写进报告；不准 commit；不碰 `tools/live2d-pipeline/**`、`skills/**`；不要用读文件工具打开任何图片；长命令显式传大 timeout，同一命令超时两次就停下写进报告；测试里不发真实网络请求；**不要运行 e2e**。
**这是纯视觉批次**：不改任何行为、状态机、协议、服务端；**保留所有现有 `data-testid`**（e2e 依赖它们，冻结点统一跑）；新元素也加 testid。不改台词；界面文案全部集中在 `apps/client/src/live/uiText.ts`（含把 `settings.ts` 里的设置文案迁过去）。

## §1 设计 token（来自 `Tokens.dc.html`）

- `--ink #120E1C`（底）、`--panel #1E1830`、`--panel-2 #241D3A`（标题栏）、`--line #3A2F55`、`--line-2 #4A3F68`
- `--text #F3EEFF`、`--text-2 #C8BEDF`、`--muted #A99CC4`、`--dim #8F82AD`
- `--accent #C9A7FF`（主色）、`--live #FF5FA2`（LIVE / 礼物）、`--listen #8FD3FF`、`--think #FFC27A`（思考 / 兜底）、`--ok #9EF0C2`
- 字体：正文 `Noto Sans SC`，系统数字 / 英文标签 `VT323`（Google Fonts，`display=swap`，加载失败回落 system-ui / monospace）。字号：字幕 22（手机 18）、名字与按钮 15、弹幕 14、辅助 12。
- 圆角：面板 10、按钮 12、胶囊 999。触控目标 ≥ 44px。

## §2 桌面布局（`Main.dc.html`）
- 去掉左侧频道栏和舞台下方黑边。整页 16px 内边距，两列网格：左 = 舞台窗口（上）+ 输入条（下，72px），右 = 360px 弹幕窗口（占两行）。
- 舞台窗口：40px 标题栏（头像、名字、LIVE 胶囊、`1 viewer · 时长`（VT323）、剧情标题 + 进度点、「文档」「观测」「设置」、模式小标签 Mock/真实）。
- 舞台右上角**状态牌**（新组件 `StateChip`，读现有 phase）：待机「发呆中」灰点；倾听「在听你说」蓝描边 + 耳朵图标；思考「想一想」琥珀三点；说话「说话中」淡紫声波柱。
- 字幕对话框：底部居中，宽 ≤ 680，「忧奈」名牌 + 正文。兜底台词（fallbackSubtitle）用琥珀名牌「忧奈 · 网络卡了」样式（文案放 uiText）。如果现有字幕状态里有逐字进度，已播部分亮、未播部分 `--dim`；**没有就整句亮显示，不要为此改字幕逻辑**。
- 说话时字幕下方显示一行小字「点画面任意位置可以打断她」（uiText），只在 speaking 显示。
- 输入条：输入框（placeholder 用现有文案）、礼物按钮（粉色图标，冷却时显示秒数）、发送、淡紫胶囊「按住说话」。
- 弹幕窗口：标题栏「弹幕」+ `CHAT · n online`；顶部是 S6m 的动作表（按 `ActionPanel.dc.html`：可展开标签，三组胶囊 / 网格按钮，预览中项高亮并显示剩余秒数）；弹幕四种样式按 `Tokens`：普通观众（彩色昵称）、你（淡紫粗体）、系统（`--dim` 居中）、引导弹幕（虚线淡紫框 + 「↳ 点一下替你说」）。

## §3 手机布局（`MobileSpeaking.dc.html`、`MobileListening.dc.html`）
- 全屏舞台；顶栏：头像胶囊（名字 + viewer + LIVE）、右侧菜单按钮；下方剧情标题胶囊 + 进度点。状态牌在右上（顶栏下方）。
- 弹幕叠在左下（最多 3 条，引导弹幕虚线框），字幕在输入条上方，输入条：圆角输入框 + 礼物 + 60px 圆形麦克风。
- **按住说话时**：底部弹出录音面板（声波条随现有 `micInputLevel`、`00:03` 计时（VT323）、「松开发送」）。设计稿上的「上滑取消」**现在没有这个功能，不要显示**。识别文字如果现有状态里有就显示在面板上方气泡里，没有就不显示。
- 菜单里：文档、观测、动作表（底部抽屉）、设置（底部抽屉）。

## §4 设置面板（`Settings.dc.html`）
- 按设计稿：三段式模式开关、三组 Key（来源标签：绿「服务器已配置」/ 紫「使用你填的」/ 琥珀「未配置」，生图未配置补「换背景用示例图」）、`type=password` + 显示切换、安全说明、「清除我的 Key」「保存并重新连接」。桌面为居中对话框，手机为底部抽屉。只改样式与结构，行为沿用 S6n。

## §5 其它页面
- 文档页、观测页、错误 / 断线提示、截图卡片、换背景状态条统一换成 token 配色（结构不变）。

## §6 验收
- `pnpm test`、`pnpm typecheck` 全绿；`PROVIDER_MODE=mock pnpm smoke` 通过。
- 在报告里列出：每个设计稿元素 → 对应组件 / CSS 位置；设计稿里有但没实现的元素及原因；新增 testid 列表；确认所有旧 testid 仍在（用 grep 对比改动前后的 testid 集合，贴出差异，应为「只增不减」）。
- 报告 `docs/tasks/s6u-report.md`。

## 关卡 1–5 结论（Claude 决定）
1. **YAGNI**：纯视觉；设计稿中依赖不存在功能的元素（上滑取消、逐字进度、实时识别气泡）有则用、无则不显示，不为视觉新增功能。
2. **端口/适配器**：不涉及。
3. **函数式核心**：状态牌的「phase → 文案 / 样式」写成纯函数并单测；其余为视图。
4. **契约式设计**：testid 只增不减；文案只在 uiText；颜色只用 token 变量。
5. **测试奖杯**：状态牌映射单测 + 现有单测全绿；e2e 冻结点统一跑；视觉由用户在浏览器验收。
