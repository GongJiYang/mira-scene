# 质量属性场景（QAW 产出）

> 来自第 3 轮 `qaw`。格式：刺激 → 环境 → 响应 → **度量**。度量值是**理论值**，S3a 预研实测后再校准。
> 每个阶段的任务说明都必须引用这里的编号，作为验收标准，因为执行 Agent 没有跨会话的记忆。

## 优先级 Top 5（用户确认）
**Q1 打断一致性 · Q3 首句延迟 · Q9 移动端 · Q8 媒体降级 · Q10 无 Key 可运行**

| # | 质量属性 | 刺激 | 环境 | 响应 | 度量 |
|---|---|---|---|---|---|
| **Q1** | 一致性·打断 | 角色说话时用户按下 PTT | 任意网络 | 语音停止，未播放的字幕/动作/媒体作废，进入倾听状态 | 按下到静音 ≤150ms；之后旧轮事件出现在画面上的次数 = 0 |
| Q2 | 一致性·迟到响应 | 旧轮次的消息晚 1–5s 才到达 | 弱网或快速连续输入 | 丢弃 | 连续打断 10 次，旧轮消息播放次数 = 0（单测 + smoke） |
| **Q3** | 响应性 | 松开 PTT 或发出文字 | 真实服务，4G | 第一句语音开始播放 | P50 ≤3s、P90 ≤5s（客户端测量；理论值：STT 0.5–1s + LLM 首句 0.8–1.5s + TTS 首句 0.6–1.2s） |
| Q4 | 响应性·状态反馈 | 任意输入 | 任意 | 视觉上进入思考或倾听状态 | ≤100ms（只改本地状态，不等服务端） |
| Q5 | 可用性·TTS 失败 | 某一句合成失败 | 真实服务 | 这一句变成无声 beat，字幕和动作照常，附轻提示 | 本轮不中断；提示 ≤1s 出现 |
| Q6 | 可用性·LLM 超时 | 首 token 超过 10s | 真实服务 | 播放兜底台词，并出现重试按钮 | 用户看不到卡死或空白 |
| Q7 | 可用性·断线 | WebSocket 断开 | 会话进行中 | 自动重连，恢复快照 | ≤10s 恢复；剧情节点不回退 |
| **Q8** | 可用性·媒体失败 | 生成图失败或超过 20s | 「翻拍立得」事件 | 改用预置照片，台词照常衔接 | 用户感知为「换了一张照片」，而不是报错 |
| **Q9** | 易用性·移动端 | iPhone Safari 首次打开 | 竖屏 | 第一次点击后有声音，没有横向滚动 | iOS 和 Android 各实测通过；动画目标 60fps、下限 30fps，低于下限时关闭网格变形 |
| **Q10** | 可演示性 | 面试官没有 Key 就 clone 下来 | 干净的机器 | Mock 模式下完整体验 3–5 分钟剧情 | 一条命令启动，≤15 分钟 |
| Q11 | 可演示性·故障注入 | 带 `?fail=` 参数打开 | 录屏时 | 稳定复现对应的降级 | 每种故障 100% 可复现 |
| Q12 | 安全·线上 | 恶意刷请求 | 已部署 | 按会话限额，超出后转为回放模式 | Key 永不出现在前端；每会话 30 轮，全站每天 300 轮 |
| Q13 | 可修改性 | 正式 UI 设计稿就绪 | 核心已完成 | 只替换视图层 | 核心代码和测试改动 0 行 |
| Q14 | 可观测性 | 任意一轮 | 开发文档窗口或观测页 | 显示各阶段耗时和事件流 | 每轮可见 4 个时间点：STT、LLM 首句、TTS、开始播放 |
