# AI 批量生成 Live2D：See-through + psd2live 自动化管线

> 本文进入开发文档窗口。要说明的观点是：**Live2D 角色可以在相当程度上由 AI 批量自动产出**。目前的管线是「自动生成为主、人工精修收尾」，等各环节稳定以后，可以升级为全自动的批量管线。

## 1. 为什么值得做

传统的 Live2D 制作流程是：原画 → 手工拆分 PSD 图层 → 在 Cubism Editor 里逐个部件做网格、变形器和参数绑定。拆层和绑定都离不开熟练的美术，一个角色通常要花上好几天。
本项目用两个开源项目，把这两个最耗人工的环节交给了算法：

| 环节 | 开源项目 | 作用 | 许可 |
|---|---|---|---|
| ① 拆层 | **See-through**（[shitagaki-lab/see-through](https://github.com/shitagaki-lab/see-through)，SIGGRAPH 2026） | 把一张动漫立绘拆成最多 23 个语义图层（前发、后发、脸、眼白、虹膜、睫毛、嘴、衣服、饰品等），**被遮挡的部分自动补画**，再按推断出的绘制顺序输出分层 PSD | 开源 |
| ② 绑定 | **psd2live**（[tsunehimatoi/psd2live](https://github.com/tsunehimatoi/psd2live)） | 读取分层 PSD 或图层清单，**自动生成网格、变形器、参数、物理效果，以及待机、眨眼、点头、摇头等动作**，导出 Cubism 的 moc3/model3.json，也可以导出自带的 p2lrt 网页运行时 | 工具为 GPL-3.0；p2lrt 运行时为 MIT |

## 2. 管线全貌

```
角色立绘（AI 生图）
  │
  ▼ ① See-through：语义拆层 + 补画遮挡（输出 768×768 的 PSD）
  │
  ▼ ② 本项目工具 tools/live2d-pipeline（Python，所有参数都写在 config.json 里）
  │    第 3 步 坐标映射：按 See-through 的补正方形和缩放反推回原图坐标，并自动校验误差
  │    第 4 步 放大回原分辨率：原图和模型补画的颜色按阈值择优；用残差检查找出丢失的部件（例如耳机）
  │    第 5 步 重建眼睛：虹膜按最小二乘拟合圆后补全，眼白取眼皮开口的实心形状，睫毛清理碎点，按左右拆分
  │    第 6 步 合成原分辨率的 PSD，拍平后和原图做色差自检
  │    补充：闭眼和口型使用画好的变体图层（eye close / mouth open，三档互斥切换）
  │
  ▼ ③ psd2live：自动绑定（--mesh-pixels），导出 Cubism 全套文件、mp4、网页播放器
  │
  ▼ ④ 自动验收：导出多种姿态（闭眼、视线、张嘴、转头），用指标打分（空洞像素、虹膜越界、残影、色差）+ 人工目测
  │
  ▼ 网页中由状态机 B（表演）驱动 Live2D 参数（眨眼、口型、视线、头部角度、表情 exp3）
```

## 3. 从「辅助」到「全自动」的升级路线

| 阶段 | 人工介入 | 现状 |
|---|---|---|
| **现在：AI 生成为主 + 人工精修** | 选人和原画由人决定；根据检查图目测验收；个别瑕疵写成修复规则 | ✅ 已经跑通（run2 → run3 → run4 迭代中） |
| 下一步：规则沉淀 | 每修一个瑕疵，就写成一条**可以自动算出来的指标和修复规则**（例如：虹膜越界像素必须为 0、内部空洞必须为 0、重复部件必须为 0），并入工具 | 正在进行：每一轮修复都同时产出对应的指标 |
| 之后：批量化 | 一条命令处理一批立绘；指标全部达标的直接产出模型，不达标的列出来交给人工精修 | 依赖各条规则稳定下来 |
| 最终：AI 精修闭环 | psd2live 提供 MCP 接口（180+ 个操作），由 AI Agent 根据指标自动做局部调整 | 规划中 |

## 4. 迭代记录（证明这条管线是被「调」出来的，而不是一次跑通）

| 轮次 | 发现的问题（来源） | 修法 |
|---|---|---|
| run1（用户手工） | 坐标映射容易出错；眼睛质量最差；睫毛方向和左右命名容易反 | 总结出 9 步流程和参数 |
| run2（工具化） | 参数写死在上一张图上；虹膜颜色写死（紫色）；耳机丢失 | 所有参数都放进 config；自动估计虹膜颜色；用残差检查补回耳机 |
| run3（修复轮 1） | 下巴和领口之间有缝、头发上有肤色竖条、闭眼时露出虹膜、虹膜有光环、睫毛有碎点、前发有锯齿（Claude 目测发现） | 8 项问题各配一个指标；闭眼改用画好的变体图层 |
| run4（修复轮 2，进行中） | 口型出现「水滴」和重影（Claude 目测）；眼球轮廓可见、往下看时眼球露出、脖子透明、头颈分离、耳坠和嘴出现重影、转头效果不佳（**用户拖动网页播放器实测发现**） | 眼白改用真实的眼皮开口形状并做裁剪；重建实心脖子；去掉重复部件；口型改为三档互斥 |

## 5. 已知限制
- 双手在同一个图层里，不会被自动拆成左右手。
- 坐姿、张腿这类姿势会让身体绑定估歪；如果原图底部被裁掉，腿部一变形就会露出断面。
- See-through 拆出的图层里可能留有重复部件，被遮挡的部分补画质量也不稳定，所以第 ② 步的规则和第 ④ 步的验收必不可少。

## 6. 专用 Skill：`skills/live2d-auto/SKILL.md`
本管线已经整理成可复用的 Agent Skill，内容包括：先决条件、两种分层输入（See-through / segly.io）、一条命令运行、各步骤的规则、自动质量门槛、人机协作边界和常见问题速查。任何 AI Agent（Claude Code、Command Code 等）加载这份 Skill 后，都能照着复跑、精修和验收。开发文档窗口会展示这一页。
