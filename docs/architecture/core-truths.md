# 这个项目的核心

> 开发文档窗口的第一页。来自第 1 轮「第一性原理」：把问题拆到不可再分的事实，再从这些事实往回推出架构。

1. **声音是线性的时间媒介。** 同一时刻只能有一个人在说话：用户一开口，角色就必须停下。所以打断不是附加功能，它是语音对话本身的物理属性。
2. **网络延迟不确定，而且可能乱序。** 系统必须有一个机制，让过期的响应失效，不管它多晚才到。这是逻辑上的必然，具体用什么方式实现可以再选。
3. **LLM 的输出不确定。** 凡是依赖 LLM 输出结构的地方，都必须有校验和降级。
4. **首句延迟等于各个串联环节的延迟之和。** 要缩短它，只有两条路：让环节并行或流水化，或者去掉某个环节。

**所以：** 评审只能看到实际运行起来的东西，因此本项目尽量部署到线上，并在界面里内置这份开发文档。
